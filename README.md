# BookHive: Library Management System for Librarians

BookHive is a web-based Library Management System developed to manage library activities easily and efficiently. The system helps librarians manage books, members, issued books, returns, and reports through a simple and responsive interface.

##  Features

* Secure admin login system.
* Add, update, search, and delete books.
* Manage library members and records.
* Issue and return books with transaction tracking.
* Generate reports for library activities.
* Responsive design for desktop and mobile devices.

---

#  Main Modules

## 1. Authentication Module

* Secure login system for administrators.

## 2. Books Management

* Add new books.
* Edit and update book details.
* Search and delete books.

## 3. Members Management

* Store and manage member information.
* Track active member records.

## 4. Issue & Return Module

* Issue books to members.
* Manage return records and transaction dates.

## 5. Reports Module

* View summaries and transaction reports.
